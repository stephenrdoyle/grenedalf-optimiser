Depth bounds per pool

grenedalf has a single depth filter for all pools, so each pool's own range is applied as a mask: a site outside any pool's range is masked in every pool, so all pools are called at the same sites. n_eff is the number of chromosomes effectively sampled at that depth from a pool of that size; depth well beyond the pool size adds little.

X chromosome and mitochondrion

X chromosome

Males carry one X, so in a pool with males the X has lower depth and is sampled from fewer copies. With a fraction m of males, X depth / autosome depth = 1 − m/2 (0.75 for a 50:50 pool), and the X pool size is the pool size × (1 − m/2). The male fraction is estimated from the depth ratio, or taken from MALE_FRACTION when the sex ratio is known, with the estimate kept as a check. If any pool differs from 1 (interval excluding it, by more than 5%), the X gets its own grenedalf run with these pool sizes; otherwise the autosomal pool size would be wrong for the X.

Filter grid

The pilot region rerun with one setting changed at a time. For each run, each statistic (θπ, θW, Tajima's D, FST) is correlated across windows with read depth, depth imbalance between the two pools of a pair, and the callable fraction of the window; none of these should matter. The artefact score is the worst median |ρ|. Runs no worse than the strictest run (within the tolerance) are accepted, and the one keeping the most data is recommended.
